测试说明与详细结果

每个节点使用独立代理连接，按订阅顺序测试。应用只保存结果，订阅链接和节点密码保留在本次运行内存中。FlClash 的 TUN 可能影响出站路径，可在上方选择实际网卡；如仍异常，请关闭 TUN 后重测。测试会占用带宽。

网络类型以多数来源展示；票数并列显示并列，分歧标黄。网络评估使用最保守类型。代理和滥用按来源计数；缺失、未配置及限流独立显示。各家分数单列，0 分仅代表该来源结果。举报数按 AbuseIPDB 近 90 天窗口保留。点节点名称查看每个 IP 的全部来源、标签与时间。

Google、Gemini 与 Claude 分别记录地区和可取得的出口 IP；不同 IP 分别查询画像，缺失明确显示未返回。未登录账号，也未验证模型回答。DNS / WebRTC 检查针对当前浏览器和系统环境，需在浏览器中单独进行。
